# Spanish glossary and style (Fuel the Ride)

Neutral Latin American Spanish. Address the rider as **tú**. Keep it short, plain and friendly, like the English.
Use "¿…?" and "¡…!" properly. Keep numbers and units exactly as in the English; translate only words.

## Rules

- Keys in `es/*.js` are the **exact** English string passed to `t()`, including punctuation, curly quotes (’ “ ”)
  and `{placeholders}`. Values keep the same `{placeholders}`, untranslated.
- Brand: **Fuel the Ride** stays in English.
- Units: `g/hr` → `g/h`, `ml/hr` → `ml/h`, `mg/hr` → `mg/h`, `kcal`, `kJ`, `W`, `bpm` (lpm is also OK, but use bpm).
- Abbreviations stay: FTP, LTHR, NP, kJ. Expand them in Spanish where the English expands them.
- Dates and numbers are formatted by the app (es-419); don't put them in translations.
- Plurals: `tn('{n} food', '{n} foods', n)` → give both keys Spanish values (`'{n} alimento'`, `'{n} alimentos'`).
